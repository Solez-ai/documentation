LifeSphere is a fully integrated autonomous caregiving ecosystem that monitors, predicts, and responds to the user across four simultaneous dimensions — medical, physical, emotional, and environmental — without requiring any interaction from the person being cared for. Five hardware subsystems share one real-time biological state backbone, enabling synchronized multi-dimensional responses that no combination of standalone devices can replicate.

## The Five Subsystems

<CardGroup cols={3}>
  <Card title="Vital32" icon="heart-pulse" href="/vital32/overview">
    14-sensor wearable biosensing layer. Predicts seizures, immune activation, and biological age in real time.
  </Card>
  <Card title="HollowRover" icon="robot" href="/hollowrover/overview">
    Autonomous mobile robot with ROS2, SLAM, UWB precision localization, and a 6-DOF caregiving arm.
  </Card>
  <Card title="SphereAI" icon="microphone" href="/sphereai/overview">
    Trimodal emotional intelligence fusing NLP, vocal prosody, and live biomarkers into adaptive companionship.
  </Card>
  <Card title="EntryGuard" icon="shield-halved" href="/entryguard/overview">
    Multi-sensor perimeter security with facial recognition and floor-aware rover dispatch.
  </Card>
  <Card title="HollowCore" icon="house-signal" href="/hollowcore/overview">

## Get Started in Four Steps

<Steps>
  <Step title="Build Vital32">
    Assemble the 14-sensor wearable on ESP32, flash the firmware, and verify live biometric data flowing to Firebase. See the [Vital32 Build Guide](/vital32/hardware).
  </Step>
  <Step title="Deploy HollowRover">
    Set up the RDK X5 compute board, run ROS2 SLAM, register floor maps with UWB anchors, and validate autonomous navigation. See the [HollowRover Build Guide](/hollowrover/hardware).
  </Step>
  <Step title="Configure SphereAI & HollowCore">
    Wire the voice hardware, install Python dependencies, and map biometric thresholds to home automation relays. See the [SphereAI Guide](/sphereai/overview) and [HollowCore Guide](/hollowcore/overview).
  </Step>
  <Step title="Integrate AI Models">
    Train and deploy the Isolation Forest, Pre-Seizure LSTM, and Emotional Classifier as TFLite models. See the [AI Pipeline Overview](/ai/pipeline-overview).
  </Step>
</Steps>

<Note>
  LifeSphere is designed so that the user **never needs to interact with any technology** — the system responds entirely to biology. Every architectural decision in this documentation reflects that principle.
</Note>
